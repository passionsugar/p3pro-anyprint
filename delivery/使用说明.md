# 随心打印 · P3 Pro

版本 1.0.1，构建日期 2026 年 11 月 11 日。

本机生成的安装包为 `P3Pro-AnyPrint-1.0.1.apk`，约 1.5 MB。包名为 `cn.paperstudio.p3print`，签名与 1.0.0 一致，支持直接覆盖安装。

## 1.0.1 实机反馈修复

- 工厂模式广播被系统拒绝后，应用记录错误并继续尝试已有权限的串口。
- 接收端同时支持 `02` 与 `07` 状态帧，支持数据拆包、粘包。图片发送采用原 APK 示例的 `02` 格式。
- 串口状态查询等待 1.5 秒，收到回复时检查缺纸、开盖等状态，查询超时则记录并继续发送。
- 自动模式可在系统服务建立连接失败时尝试本机串口。
- 设置与打印进度面板新增“复制诊断”，包含版本、UID、服务查询、原始串口收发与异常堆栈。

## 安装与首次打印

1. 将 APK 传到 P3 Pro，在机器的文件管理器中打开并安装。已有 1.0.0 可直接覆盖安装。
2. 打开“随心打印”，点击右上角进入打印机设置。默认采用“自动 · 优先系统 mbprint 服务”。
3. 先使用“文本打印”输入少量文字，点击“预览并打印”，检查预览，再点击“打印文本”和“开始打印”。
4. 如果系统服务不可用，可按机器型号选择“原生串口 · Wi-Fi 版”或“原生串口 · 4G 版”。界面会报告缺纸、开盖、超时或权限问题。
5. 复测截图中的 Wi-Fi 串口模式前，先在 P30ProSettingTool 中点击“断开”，再切回本应用。截图中该工具仍处于连接状态。
6. 遇到失败，点击“复制诊断”，将文字粘贴回传。也可以使用“导出诊断”保存 TXT 文件。

实机照片确认了 Android 8.1 P3 Pro 的页面显示、系统服务枚举及串口读写权限检查。维护者于 2026-11-14 反馈 1.0.1 已在 P3 Pro 实机使用成功，具体连接模式和文件类型覆盖范围尚未记录。

## 图片打印

- 选择一张或多张图片，勾选要打印的项目。列表的上下箭头调整顺序。
- 所有图片按原始比例适应 864 点纸宽，透明背景转换为白色。点击列表可预览。
- 极短图片在提交前居中补白到至少 32 行，避免原厂算法在单行输入上的不稳定行为，图片内容和宽度保持原值。
- 已检查 JPEG、PNG、WebP、24 位 BMP、GIF、TIFF 和 SVG 的导入或转换。
- GIF 和多页 TIFF 当前使用第一帧或第一页。HEIF、HEIC 和 AVIF 取决于设备系统解码能力，无法解码时会显示错误。
- 原生串口模式调用原 APK 的图片算法，缩放、二值化与其内置示例使用同一个 JNI 入口。

## 文档打印

- PDF 按页转成 864 点宽图片，支持全部打印以及 `1-3,5` 形式的页码选择。重复页码会去重，顺序按输入保留。
- Markdown 支持标题、列表、表格、代码块和数学公式。
- TXT 支持 UTF-8、UTF-8 BOM、UTF-16 BOM 和常见中文 GB18030 编码。
- Markdown 图片可使用内嵌 Base64 的 PNG、JPEG、GIF、WebP 或 BMP。本机相对路径与网络图片会显示提示，可将图片内嵌文档或通过图片打印单独选择。
- 长 Markdown 与文本按行间位置自动分页，每个分段作为一张位图提交。实际分段间距取决于打印机固件。

## 文本打印

编辑器采用 Quill，提供粗体、斜体、下划线、删除线、字号、标题、列表、撤销和重做。

把光标放在一行内，再点击对齐按钮即可设置该行。选择跨越多行的文字后点击对齐按钮，可同时设置这些段落。支持左对齐、居中和右对齐。

富文本和 Markdown 各自保存独立草稿。输入内容后可切换到预览，打印字号控制实际纸面字号。“公式示例”会填入 Markdown 示例草稿。

### 数学公式

以下五种形式均已在 APK 的 Android WebView 中检查。

```tex
$\LaTeX$

$$\LaTeX$$

\[ \LaTeX \]

\( \LaTeX \)

\[
\LaTeX
\]
```

也可以点击工具栏的 `fx`，输入 LaTeX 并选择行内或独立公式行。数学排版采用离线 KaTeX，支持其语法范围内的分式、根式、积分、矩阵等。渲染错误的公式会阻止提交，便于先修正内容。

## 打印接口与任务状态

默认优先使用从“拍题录入&学习簿”中还原的 `mbprint` 系统服务。服务存在但拒绝访问或提交失败时，界面会显示错误。

自动模式在服务连接失败时选择原 APK 的串口路径。原生串口尝试广播申请释放，广播被拒绝时继续打开可读写串口。归还广播仅对应已接受的释放请求。

“停止后续打印”会停止尚未提交的页面。系统已接收的当前页可能继续打印。超时或中途失败后请核对出纸情况，重新打印会创建新的任务。

系统服务结束回调中的 `0` 当前按正常结束处理，其他数值展示给用户。原客户端没有说明该参数的完整语义，需由实机日志继续确认。串口界面的“数据已发送”表示传输结束。

## 文件与设备要求

- 主要布局按 534×320 横屏设计，软键盘出现后保留底部操作区。
- APK 的最低安装版本为 Android 5.0。已验证的运行环境为 Android 9、WebView 69，其他系统与旧 WebView 的兼容性待实机确认。
- 文件选择优先使用系统选择器。系统缺少选择器时，应用提供本机文件浏览器并请求读取存储权限。
- 单个文件上限 128 MB，文本上限 2 MB，一次最多导入 100 个文件。PDF 上限 500 页，单次任务上限 1000 页，份数范围为 1–20。
- 单张图片缩放后的高度上限为 20000 点，超长图片需要先分割。导入前要求至少 160 MB 可用空间。
- 导入副本放在应用会话缓存中，重新打开时需要重新选择文件。富文本与 Markdown 草稿单独保存在本机 WebView 存储中。
